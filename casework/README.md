# Casework

A deduction game with fifty-two cases, **The spare key**, **The rehearsal score**, **The gilt stamp**, **The ferry bell**, **The weather slate**, **The loom shuttle**, **The hive smoker**, **The glass pontil**, **The press proof**, **The assay cup**, **The kiln chalk**, **The tide ledger**, **The night bell**, **The salt mark**, **The wick trim**, **The glass anneal**, **The orchard graft**, **The dye vat**, **The tar kettle**, **The cork press**, **The net loft**, **The cask hoop**, **The linen fold**, **The dovetail**, **The mortise**, **The rebate**, **The housing**, **The tenon**, **The bridle**, **The dado**, **The spline**, **The mitre**, **The lap**, **The scarf**, **The finger**, **The haunch**, **The dowel**, **The tongue**, **The quirk**, **The chamfer**, **The scotia**, **The cyma**, **The cavetto**, **The reed**, **The annulet**, **The hood**, **The listel**, **The abacus**, **The girdle**, **The reglet**, **The gutta**, and **The mutule**.

Pick a file. That file keeps a single timeline. You read the exhibits and pin who, the room, and the hour. A theory is accepted only when it fits every exhibit. A theory that does not fit comes back naming the exhibits it contradicts. An empty pin is refused by the name of the missing slot.

There is no voice. The papers and the board are the whole case.

## Play

Requires Godot 4. From this folder:

```
godot --path .
```

From the repository root:

```
godot --path casework
```

You can also open `project.godot` in the Godot 4 editor and press Play.

## Test

Requires Godot 4. From this folder:

```
godot --headless --path . -s res://tests/run.gd
```

The process exits 0 when every check passes and non-zero when any check fails.
